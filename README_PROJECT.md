# PAOS — Personal AI OS

## 解决了什么问题

**问题**：个人信息和知识碎片化——从社交媒体、RSS、文章等渠道获取的内容散落各处，难以系统性沉淀和复用。

## 解决方案

PAOS 是一个**个人 AI 操作系统**，以本地计算为中枢，将碎片化信息自动提纯为结构化知识，并支持自动生成文章。

## 运行流程

### 1. 安装与启动
```bash
./install.sh
source .venv/bin/activate
uvicorn paos.main:app --reload
# 服务默认运行在 http://127.0.0.1:8000
```

### 2. 提交输入
```bash
curl -X POST http://127.0.0.1:8000/api/v1/input \
  -H "Content-Type: application/json" \
  -d '{"source": "natural_language", "data": {"content": "你的灵感/笔记内容"}}'
```

### 3. 自动提纯（后台自动完成）
```
用户输入 → 原始存储 → LLM 摘要+标签 → 结构化存储 → 索引更新
```

### 4. 生成文章
```bash
curl -X POST "http://127.0.0.1:8000/api/v1/generate/article?limit=5"
```

## 核心功能

### 信息提纯
- 自动将原始输入转为带摘要和标签的结构化知识
- 支持自然语言、RSS、搜索等多种输入源

### 三重存储
| 层级 | 存储位置 |
|------|----------|
| 原始输入 | `data/raw/` + `paos.db` |
| 提纯知识 | `data/processed/` + `paos.db` |
| 生成输出 | `data/output/` |

### MCP Server
PAOS 内置 MCP Server，可供外部 Agent 调用：
```bash
python -m paos.mcp_server  # stdio 模式
python -m paos.mcp_server --sse --port 8001  # SSE 模式
```

已暴露工具：`paos_list_index`、`paos_web_search`、`paos_generate_article` 等 12 个工具。

### Fallback 机制
当 LLM API 不可用时，系统自动将请求排入 fallback 队列，由对话中的 Agent 补全。

## 配置管理

所有配置集中在 `paos/config/default.yaml`，支持环境变量覆盖：
- `PAOS_LLM__API_KEY` — LLM API 密钥
- `PAOS_LLM__MODEL` — 模型名称
- `PAOS_SERVER__PORT` — 服务端口
